# Imágenes de productos

El catálogo y la página de detalle buscan en esta carpeta un archivo cuyo nombre coincida con el `id_producto`, por ejemplo `img/16.jpg` para el producto con ID 16. Se admiten las extensiones AVIF, GIF, JPEG, JPG, PNG y WebP.

Las imágenes guardadas en `uploads/` o en la columna `Productos.imagen` tienen prioridad. No se asignan imágenes buscando palabras en el nombre del producto.
